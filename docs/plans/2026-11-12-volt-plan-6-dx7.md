# Volt Plan 6 — DX7-Compatible FM Engine Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Volt 1.1.0 plays DX7 patches:
- a second voice type, 6-operator FM, built on the msfa core;
- the 8 DX7 factory cartridges (256 voices) in the preset browser;
- `.syx` import and export;
- a full FM patch editor on the phone.

**Architecture:**
- **Voice type.** A new parameter, `engine.type` (0 analog, 1 FM), selects what every voice plays.
- **FM DSP.** An `FmBlock` owned by the `Engine` wraps 16 msfa `Dx7Note`s, one msfa `Lfo` and one msfa `Controllers`. It renders in msfa's 64-sample chunks and hands 16-sample blocks to the engine's existing effect chain and limiter.
- **Patch data.** Every DX7 voice parameter is an ordinary entry in `params.def`, in VCED order. Building the 156-byte msfa patch is then one loop over the parameter values.
- **`.syx` reading.** It is implemented twice with identical behaviour: C++ for PC tests, Kotlin for the app.

**Tech Stack:**
- C++20 engine (existing) plus `third_party/Synth_Dexed` (git submodule; its msfa sources are Apache 2.0, the rest is GPL-3; we compile only msfa files);
- Kotlin 2.3 + Jetpack Compose;
- JUnit 4.

### DX7 data formats (the facts the codecs need)

**Single-voice data ("VCED"), 155 bytes.** msfa's `Dx7Note` takes these as `patch[156]`, and byte 155 is unused.
- **Six operator blocks of 21 bytes, OP6 first** (bytes 0–20 are OP6, …, bytes 105–125 are OP1). Within a block:

| Offset | Field | Range |
|---|---|---|
| 0–3 | R1–R4 (envelope rates) | 0–99 |
| 4–7 | L1–L4 (envelope levels) | 0–99 |
| 8 | break point | 0–99 (39 = C3) |
| 9 | left depth | 0–99 |
| 10 | right depth | 0–99 |
| 11 | left curve | 0–3 (-LIN, -EXP, +EXP, +LIN) |
| 12 | right curve | 0–3 |
| 13 | rate scaling | 0–7 |
| 14 | amp-mod sensitivity | 0–3 |
| 15 | key velocity sensitivity | 0–7 |
| 16 | output level | 0–99 |
| 17 | oscillator mode | 0 ratio, 1 fixed |
| 18 | frequency coarse | 0–31 |
| 19 | frequency fine | 0–99 |
| 20 | detune | 0–14, 7 = centre |

- **Global block:**

| Byte | Field | Range |
|---|---|---|
| 126–129 | pitch EG rates | 0–99 |
| 130–133 | pitch EG levels | 0–99 (50 = no shift) |
| 134 | algorithm | 0–31 |
| 135 | feedback | 0–7 |
| 136 | osc key sync | 0–1 |
| 137 | LFO speed | 0–99 |
| 138 | LFO delay | 0–99 |
| 139 | LFO PMD | 0–99 |
| 140 | LFO AMD | 0–99 |
| 141 | LFO key sync | 0–1 |
| 142 | LFO wave | 0–5: triangle, saw down, saw up, square, sine, sample&hold |
| 143 | LFO pitch-mod sensitivity | 0–7 |
| 144 | transpose | 0–48, 24 = C3 |
| 145–154 | name | 10 ASCII characters |

**Packed voice ("VMEM"), 128 bytes, as in a 32-voice bank.**
- **Operator blocks:** six blocks of 17 bytes, OP6 first. Within block `o` (byte offset `o*17`):
  - bytes 0–10: the same as VCED 0–10;
  - byte 11: `RC<<2 | LC`;
  - byte 12: `DET<<3 | RS`;
  - byte 13: `KVS<<2 | AMS`;
  - byte 14: OL;
  - byte 15: `FC<<1 | M`;
  - byte 16: FF.
- **Global bytes:**
  - bytes 102–109: pitch EG, as VCED 126–133;
  - byte 110: algorithm, as `ALG & 0x1F`;
  - byte 111: `OKS<<3 | FB`;
  - bytes 112–115: LFO speed, delay, PMD and AMD;
  - byte 116: `LPMS<<4 | LFW<<1 | LKS`;
  - byte 117: transpose;
  - bytes 118–127: name.

**Bank sysex ("32 voices"), 4104 bytes:** `F0 43 0n 09 20 00`, then 4096 bytes (32 × VMEM), then a checksum, then `F7`. The checksum is `(-sum(4096 bytes)) & 0x7F`.

**Single-voice sysex, 163 bytes:** `F0 43 0n 00 01 1B`, then 155 VCED bytes, then the checksum of those 155 bytes, then `F7`.

`n` is the MIDI channel (0–15). On read, accept any `n`; on write, use 0.

**Out-of-range bytes** occur in old cartridges, where bit 7 or unused high bits are set. On read:
- mask each byte with `0x7F`;
- unpack the packed fields with their bit masks;
- clamp every field to the range in the table above.
The DX7 itself does the same.

### msfa API used (Synth_Dexed `src/`, read the headers to confirm)

- **Static tables, set once per sample rate, off the audio thread:**
  - `Exp2::init()`, `Tanh::init()`, `Sin::init()`;
  - `Freqlut::init(sr)`, `Lfo::init(sr)`, `PitchEnv::init(sr)`, `Env::init_sr(sr)`, `Porta::init_sr(sr)`.
- **`Dx7Note`:**
  - `init(patch, midinote, velocity0to127, srcnote, porta, &ctrls)`: pass `porta = -1` for no portamento;
  - `compute(int32_t* buf64, lfoVal, lfoDelay, &ctrls)`: **adds** 64 samples into `buf`;
  - `keyup()`;
  - `update(patch, midinote, velocity, porta, &ctrls)`: applies an edited patch to a sounding note;
  - `oscSync()`: call after `init` when byte 136 is 1;
  - `peekVoiceStatus(VoiceStatus&)`: `amp[op]` and `ampStep[op]`; step 4 means the envelope has ended.
- **`Lfo`** (msfa's, in the global namespace; not `volt::Lfo`):
  - `reset(patch + 137)`;
  - `keydown()` on each note-on;
  - `getsample()` and `getdelay()`, once per 64-sample chunk.
- **`Controllers`:**
  - `values_[kControllerPitch]`: 0..16383, centre 0x2000;
  - `values_[kControllerPitchRange]`: semitones;
  - `values_[kControllerPitchStep]`: 0;
  - `values_[kControllerPortamentoGlissando]`: 0;
  - `modwheel_cc`, `aftertouch_cc`, `breath_cc`, `foot_cc`: each 0..127;
  - `wheel`, `at`, `breath`, `foot` (`FmMod`): `setRange(0..99)` and `setTarget(bits: 1 pitch, 2 amp, 4 EG)`;
  - `refresh()` after any change;
  - `masterTune` = 0;
  - `opSwitch`: bit `i` enables msfa operator index `i`, where **index 0 = OP6**;
  - `core`: must point to an `EngineMsfa` instance (`EngineMsfa.cpp`), which does the actual rendering.
- **Include trap (found in Task 1).** `engine/src/lfo.h` (`volt::Lfo`) shadows msfa's `lfo.h`, because `engine/src` comes first on the include path. Anywhere under `engine/src` or `engine/tests` that needs msfa's `::Lfo`, include it by path: `#include "../../third_party/Synth_Dexed/src/lfo.h"` (adjust the number of `../` to the file's depth). It is the only msfa header name that collides. msfa's `init` functions take a `float` sample rate (`FRAC_NUM`), not `double`. The test helpers are `probe::zeroCrossHz(x, sr)` (not `probe::frequency`) and `probe::rms` (returns `double`); wherever later tasks use `probe::frequency`, use `probe::zeroCrossHz` instead.
- **Carriers:** `FmCore::get_carrier_operators(alg0to31)` returns a bitmask, also in msfa operator order (bit 0 = OP6).
- **Algorithm topology:** `FmCore::algorithms[32]` is `protected static`. A subclass may read it (Task 12 uses that).
- **Output scaling.** One chunk's `int32` sum becomes float as `sample = clamp(buf >> 13, -32768, 32767) / 32768.0f`. That is what Synth_Dexed does (`signed_saturate_rshift(x >> 4, 24, 9) / 32768`). Keep the same scale so the adapter test can compare bit-for-bit.
- **Voice end.** A voice is free when every carrier has `ampStep == 4` and `amp <= VOICE_SILENCE_LEVEL` (1100, defined in `synth.h`).

### Findings during execution (keep for NOTES in Task 16)

- **Cartridge round trip is byte-identical for 5 of the 8 files, not all 8.** `rom3a`, `rom3b` and `rom4a` carry bits the DX7 itself ignores (unused high bits, e.g. packed byte 111 holding `0x19` where only `0x0F` is meaningful) and a few out-of-range values (127 or 100 in 0..99 fields). Mask-and-clamp changes those bytes, so writing the bank back differs from the original in 7 voices. Verified in Task 3: `rom3a` voices 1, 3, 14, 19, 21; `rom3b` voices 1, 3, 14; `rom4a` voice 7. The rule is therefore: `rom1a`, `rom1b`, `rom2a`, `rom2b`, `rom4b` are byte-identical on round trip; the other three satisfy `unpack -> pack -> unpack` (voices equal, and the second written bank equals the first). The Kotlin codec test (Task 8) uses the same two-tier rule.
- Counts: after Task 2 `kNumParams` is 263 (99 old + 164 FM), not 67 + 164; wherever this plan says 67, read 99.

### Decisions taken while writing this plan (report them to the user at the end)

1. **Synth_Dexed instead of Dexed.** The design said "Dexed's msfa". Current Dexed's msfa depends on JUCE, MTS-ESP and Dexed's logger, so it does not build alone. Synth_Dexed (`codeberg.org/dcoredump/Synth_Dexed`) is the same msfa engine, already extracted from Dexed for hardware synths. It has no JUCE, and its msfa files carry the original Apache 2.0 headers, which are compatible with our GPL-3. The design allowed this: "the exact choice of files is an implementation decision, recorded in NOTES".
2. **FM voices are mono and centred,** like the DX7. Pan and stereo come from the effects (chorus, delay, reverb).
3. **Voice modes in FM:** `poly` works as usual.
   - `mono`, `legato` and `unison` all play one voice with retrigger. msfa has no legato pitch retarget, and DX7 unison would need per-voice detune that msfa lacks.
   - `voice.glide` is ignored in FM, because DX7 portamento lives in the "function" settings, not in the voice.
   - `voice.bend` (the bend range) and the sustain pedal work.
   - `voice.drift` is ignored.
4. **FM note timing is quantised to 64 samples (1.3 ms),** like Dexed. Note-ons land at the next chunk boundary.
5. **The operator on/off switches are preset parameters** (`fm.opN.on`). On a real DX7 they are a temporary panel state; here they save with the preset, and default on. Export to `.syx` ignores them.
6. **The DX7 "function" controller settings live in the preset:**
   - mod wheel, aftertouch and breath, each with a range and pitch/amp/EG targets;
   - defaults are wheel 50 with pitch on, the others 0.
   - `.syx` has no place for them, so a voice read from a cartridge gets the defaults.
7. **Single-voice sysex export** is in scope (design section 5). **Exporting a whole category as a 32-voice bank** is limited to user categories that hold FM presets. Presets beyond 32 are dropped with a warning; if there are fewer than 32, the rest of the bank is filled with INIT VOICE.
8. **The preset name in a `.syx`** is trimmed of trailing spaces on read. On write it is padded or cut to 10 characters, and non-ASCII characters become `?`.

```cpp
#include "fm/dx7_codec.h"
#include <cstring>

namespace volt {

namespace {
// Maximum of each VCED operator field (offsets 0..20).
constexpr uint8_t kOpMax[21] = {99, 99, 99, 99, 99, 99, 99, 99, 99, 99, 99, 3, 3, 7, 3, 7, 99, 1, 31, 99, 14};
// Maximum of each global field, bytes 126..144.
constexpr uint8_t kGlobalMax[19] = {99, 99, 99, 99, 99, 99, 99, 99, 31, 7, 1, 99, 99, 99, 99, 1, 5, 7, 48};

uint8_t checksum(const uint8_t* data, int n) {
  int sum = 0;
  for (int i = 0; i < n; ++i) sum += data[i];
  return (uint8_t)((-sum) & 0x7F);
}
uint8_t clampTo(int v, int max) { return (uint8_t)(v < 0 ? 0 : (v > max ? max : v)); }
}  // namespace

void clampVced(Dx7Voice& v) {
  for (int op = 0; op < 6; ++op)
    for (int k = 0; k < 21; ++k) v[op * 21 + k] = clampTo(v[op * 21 + k] & 0x7F, kOpMax[k]);
  for (int g = 0; g < 19; ++g) v[126 + g] = clampTo(v[126 + g] & 0x7F, kGlobalMax[g]);
  for (int i = 145; i < 155; ++i) { uint8_t c = v[i] & 0x7F; v[i] = (c < 32) ? ' ' : c; }
  v[155] = 0;
}

void unpackVmem(const uint8_t* m, Dx7Voice& v) {
  v.fill(0);
  for (int op = 0; op < 6; ++op) {
    const uint8_t* s = m + op * 17;
    uint8_t* d = v.data() + op * 21;
    for (int k = 0; k < 11; ++k) d[k] = s[k] & 0x7F;
    d[11] = s[11] & 0x03;          // left curve
    d[12] = (s[11] >> 2) & 0x03;   // right curve
    d[13] = s[12] & 0x07;          // rate scaling
    d[20] = (s[12] >> 3) & 0x0F;   // detune
    d[14] = s[13] & 0x03;          // AMS
    d[15] = (s[13] >> 2) & 0x07;   // KVS
    d[16] = s[14] & 0x7F;          // output level
    d[17] = s[15] & 0x01;          // mode
    d[18] = (s[15] >> 1) & 0x1F;   // coarse
    d[19] = s[16] & 0x7F;          // fine
  }
  for (int i = 0; i < 8; ++i) v[126 + i] = m[102 + i] & 0x7F;
  v[134] = m[110] & 0x1F;
  v[135] = m[111] & 0x07;
  v[136] = (m[111] >> 3) & 0x01;
  for (int i = 0; i < 4; ++i) v[137 + i] = m[112 + i] & 0x7F;
  v[141] = m[116] & 0x01;
  v[142] = (m[116] >> 1) & 0x07;
  v[143] = (m[116] >> 4) & 0x07;
  v[144] = m[117] & 0x7F;
  for (int i = 0; i < 10; ++i) v[145 + i] = m[118 + i];
  clampVced(v);
}

void packVmem(const Dx7Voice& v, uint8_t* m) {
  std::memset(m, 0, 128);
  for (int op = 0; op < 6; ++op) {
    const uint8_t* s = v.data() + op * 21;
    uint8_t* d = m + op * 17;
    for (int k = 0; k < 11; ++k) d[k] = s[k];
    d[11] = (uint8_t)((s[12] << 2) | s[11]);
    d[12] = (uint8_t)((s[20] << 3) | s[13]);
    d[13] = (uint8_t)((s[15] << 2) | s[14]);
    d[14] = s[16];
    d[15] = (uint8_t)((s[18] << 1) | s[17]);
    d[16] = s[19];
  }
  for (int i = 0; i < 8; ++i) m[102 + i] = v[126 + i];
  m[110] = v[134];
  m[111] = (uint8_t)((v[136] << 3) | v[135]);
  for (int i = 0; i < 4; ++i) m[112 + i] = v[137 + i];
  m[116] = (uint8_t)((v[143] << 4) | (v[142] << 1) | v[141]);
  m[117] = v[144];
  for (int i = 0; i < 10; ++i) m[118 + i] = v[145 + i];
}

Dx7Status readDx7Bank(const std::vector<uint8_t>& s, Dx7Bank& out) {
  if (s.size() != 4104 || s[0] != 0xF0 || s[1] != 0x43 || (s[2] & 0xF0) != 0x00 || s[3] != 0x09 ||
      s[4] != 0x20 || s[5] != 0x00 || s[4103] != 0xF7)
    return Dx7Status::NotDx7;
  for (int i = 0; i < 32; ++i) unpackVmem(s.data() + 6 + i * 128, out.voices[i]);
  return checksum(s.data() + 6, 4096) == (s[4102] & 0x7F) ? Dx7Status::Ok : Dx7Status::BadChecksum;
}

std::vector<uint8_t> writeDx7Bank(const Dx7Bank& b) {
  std::vector<uint8_t> s = {0xF0, 0x43, 0x00, 0x09, 0x20, 0x00};
  s.resize(6 + 4096);
  for (int i = 0; i < 32; ++i) packVmem(b.voices[i], s.data() + 6 + i * 128);
  s.push_back(checksum(s.data() + 6, 4096));
  s.push_back(0xF7);
  return s;
}

Dx7Status readDx7Voice(const std::vector<uint8_t>& s, Dx7Voice& out) {
  if (s.size() != 163 || s[0] != 0xF0 || s[1] != 0x43 || (s[2] & 0xF0) != 0x00 || s[3] != 0x00 ||
      s[4] != 0x01 || s[5] != 0x1B || s[162] != 0xF7)
    return Dx7Status::NotDx7;
  out.fill(0);
  for (int i = 0; i < 155; ++i) out[i] = s[6 + i];
  clampVced(out);
  return checksum(s.data() + 6, 155) == (s[161] & 0x7F) ? Dx7Status::Ok : Dx7Status::BadChecksum;
}

std::vector<uint8_t> writeDx7Voice(const Dx7Voice& v) {
  std::vector<uint8_t> s = {0xF0, 0x43, 0x00, 0x00, 0x01, 0x1B};
  for (int i = 0; i < 155; ++i) s.push_back(v[i]);
  s.push_back(checksum(v.data(), 155));
  s.push_back(0xF7);
  return s;
}

std::string dx7Name(const uint8_t* v) {
  std::string n(reinterpret_cast<const char*>(v + 145), 10);
  while (!n.empty() && n.back() == ' ') n.pop_back();
  return n;
}

void setDx7Name(Dx7Voice& v, const std::string& name) {
  for (int i = 0; i < 10; ++i) {
    char c = i < (int)name.size() ? name[i] : ' ';
    v[145 + i] = (unsigned char)c >= 32 && (unsigned char)c < 127 ? (uint8_t)c : (uint8_t)'?';
  }
}

}  // namespace volt
```

```cpp
#include "fm/fm_params.h"
#include <cmath>
#include "params.h"

namespace volt {

namespace {
int vcedOffsetOfOp(int n) { return (6 - n) * 21; }  // n = 1..6 (OP1..OP6)
int globalOffset(int g) { return g == 8 ? -1 : (g == 18 ? 24 : 0); }  // algorithm 1..32, transpose -24..24
int opOffset(int k) { return k == 20 ? 7 : 0; }                         // detune -7..7
}  // namespace

void vcedFromValues(const float* v, Dx7Voice& p) {
  p.fill(0);
  for (int n = 1; n <= 6; ++n) {
    const int base = kFmOp1R1 + (n - 1) * kFmOpStride;
    for (int k = 0; k < 21; ++k) p[vcedOffsetOfOp(n) + k] = (uint8_t)std::lround(v[base + k] + opOffset(k));
  }
  for (int g = 0; g < kFmGlobalCount; ++g) p[126 + g] = (uint8_t)std::lround(v[kFmPitchEnvR1 + g] + globalOffset(g));
  for (int i = 145; i < 155; ++i) p[i] = ' ';
  clampVced(p);
}

void valuesFromVced(const Dx7Voice& p, float* v) {
  for (int n = 1; n <= 6; ++n) {
    const int base = kFmOp1R1 + (n - 1) * kFmOpStride;
    for (int k = 0; k < 21; ++k) v[base + k] = (float)(p[vcedOffsetOfOp(n) + k] - opOffset(k));
    v[base + 21] = 1.0f;  // operator on
  }
  for (int g = 0; g < kFmGlobalCount; ++g) v[kFmPitchEnvR1 + g] = (float)(p[126 + g] - globalOffset(g));
  v[kEngineType] = 1.0f;
}

uint8_t opSwitchFromValues(const float* v) {
```

```cpp
#pragma once
#include <cstdint>
#include <memory>
#include "util.h"

namespace volt {

// 6-operator FM voices (msfa, DX7-compatible). Mono output, summed into the caller's buffer.
// Audio thread: everything except the constructor and setSampleRate().
class FmBlock {
 public:
  FmBlock();
  ~FmBlock();
  void setSampleRate(float sr);          // not on the audio thread: fills msfa's static tables

  // Real parameter values (ParamId order). Rebuilds the msfa patch and updates sounding voices.
  void setPatch(const float* value);

  void noteOn(int slot, int note, float velocity, float gain);  // velocity 0..1
  void noteOff(int slot);                // key up: envelopes go to their release stage
  void quickRelease(int slot);           // 15 ms fade, then free (polyphony limit)
  void kill(int slot);                   // silent and free now (panic, patch change)
  bool active(int slot) const;

  void setBend(float bend, int rangeSemis);   // bend -1..1
  void setModWheel(float v);                  // 0..1
  void setAftertouch(float v);                // 0..1
  void setBreath(float v);                    // 0..1

  // Adds `frames` mono samples (any count; internally 64-sample chunks) into out.
  void render(float* out, int frames);

 private:
  struct Impl;
  std::unique_ptr<Impl> m_;
};

}  // namespace volt
```

`engine/src/fm/fm_block.cpp`. Write it with these rules:
- **`Impl` members:**
  - `EngineMsfa core`; `Controllers ctrl`; `::Lfo lfo`;
  - `Dx7Voice patch`; `uint8_t carriers`;
  - per slot: `Dx7Note note[kMaxVoices]`, `bool live[kMaxVoices]`, `int midiNote[kMaxVoices]`, `int velocity[kMaxVoices]`;
  - per slot: `float gain[kMaxVoices]`, `float fade[kMaxVoices]` (1 = no fade), `float fadeStep[kMaxVoices]`;
  - `float chunk[64]`; `int pos = 64` (64 = the chunk is used up).
- **Constructor:** `ctrl.core = &core`. Neutral controller values, as in the msfa test of Task 1. `opSwitch = 0x3f`, then `refresh()`.
- **`setSampleRate(sr)`:** call the nine `init` functions. msfa tables are global statics, so a second `FmBlock` re-initialises the same tables (harmless: same values).
- **`setPatch(value)`:**
  - `vcedFromValues(value, patch)`;
  - `ctrl.opSwitch = opSwitchFromValues(value)`;
  - controller routing: `ctrl.wheel.setRange((uint8_t)value[kFmWheelRange])` and `ctrl.wheel.setTarget(pitch | amp<<1 | eg<<2)`, the same for `at` and `breath`, then `ctrl.refresh()`;
  - `lfo.reset(patch.data() + 137)`;
  - `carriers = FmCore::get_carrier_operators(patch[134])`;
  - for each live slot: `note[s].update(patch.data(), midiNote[s], velocity[s], -1, &ctrl)`.
  
  `setPatch` must not allocate.
- **`noteOn(slot, note, vel, gain)`:**
  - `midi = note + patch[144] - 24`, clamped to 0..127;
  - `velocity[slot] = clamp(lround(vel * 127), 1, 127)`;
  - `lfo.keydown()`;
  - `note[slot].init(patch.data(), midi, velocity, midi, -1, &ctrl)`;
  - if `patch[136]`, call `note[slot].oscSync()`;
  - `live = true`, `fade = 1`, `fadeStep = 0`, store `gain`.
- **`noteOff`:** `note[slot].keyup()`.
- **`quickRelease`:** `fadeStep = 1 / (0.015 * sr)`. When `fade` reaches 0, set `live = false`.
- **`kill`:** `live = false`.
- **`setBend`:** `ctrl.values_[kControllerPitch] = 0x2000 + lround(bend * 8191)` and `values_[kControllerPitchRange] = range`.
- **The other controllers:** set `modwheel_cc` / `aftertouch_cc` / `breath_cc` to `lround(v * 127)`, then `refresh()`.
- **`render(out, frames)`:** loop. When `pos == 64`, compute a chunk:
  - zero `chunk`;
  - `lv = lfo.getsample()`, `ld = lfo.getdelay()`;
  - for each live slot:
    - zero a local `int32_t buf[64]`, then `note[s].compute(buf, lv, ld, &ctrl)`;
    - convert each sample: `x = clamp(buf[i] >> 13, -32768, 32767) / 32768.f`;
    - multiply by `gain[s]` and by `fade[s]`, stepping `fade[s]` per sample;
    - add into `chunk`;
    - then run the silence check: `peekVoiceStatus`; for every carrier bit `i` in `carriers`, require `ampStep[i] == 4 && amp[i] <= VOICE_SILENCE_LEVEL`. If all carriers are silent, or `fade <= 0`, set `live = false`.
  - set `pos = 0`.
  
  Then copy `min(frames, 64 - pos)` samples from `chunk[pos]` into `out` (adding), and advance.

Unused `noteOn` slot numbers ≥ `kMaxVoices` are ignored. `velocity` and `midiNote` keep their last values for `update`.

**Design inside the engine:**
- **Bookkeeping stays in `Voice`.** The `Voice` objects keep doing the bookkeeping for both voice types: `active`, `held`, `sustained`, `note` and `age`, plus allocation, stealing, sustain and the voice limit. In FM mode the engine calls `FmBlock` alongside every voice state change, and never calls `Voice::pre/post`.
  - `Voice::start` is still called. It sets the bookkeeping fields, and the analog state it also prepares is simply never rendered.
  - At the end of each block, a voice whose `FmBlock` slot is no longer active gets `v.kill()`, so `active` follows the FM envelope.
- **Mode switch.** `fm_` is `engine.type` after the patch is applied. `applyPending()` is where a patch changes `engine.type`. Before that, the fade-out has already silenced the voices, so on a change of type, kill every voice (`v.kill()` and `fm_->kill(i)`). Then the fade-in starts on silence.
- **`SetParam` of an `fm.*` id** (`id >= kFmOp1R1`) or of `engine.type`:
  - `engine.type` takes effect at once: kill all voices, so there is no click, because a type change from the UI is rare and deliberate;
  - any `fm.*` change calls `fm_->setPatch(value_)` after updating `value_`;
  - `applyPending()` also calls `setPatch`.
- **Rendering in FM mode:** `fm_->render(monoBlock, kBlock)`, then add to both `blockL_` and `blockR_` (mono, centred). Effects, master volume, the limiter and the fade stay as they are.
- **Gain:** `kFmGain` is a constant in `engine.cpp`, starting at 1.0. It is passed as `gain` to `fm_->noteOn` (Task 7 calibrates it).
- **New events:** `Aftertouch` (`b` 0..1) and `Breath` (`b` 0..1). Analog mode ignores them. `ModWheel` and `PitchBend` go to both the analog path and `fm_`; `setBend` uses `value_[kVoiceBend]`.
- **Voice modes in FM** (decision 3): in `noteOn`, if `fm_` and the mode is not poly, play one voice (index 0) with retrigger.

```kotlin
package com.criapix.volt.preset

/** DX7 sysex: 32-voice banks and single voices (plan 6, section 0). No Android types. */
object Dx7Codec {
  data class Read(val presets: List<PresetFile>, val checksumOk: Boolean)

  private val OP_FIELDS = listOf("r1", "r2", "r3", "r4", "l1", "l2", "l3", "l4", "kls.break", "kls.ldepth", "kls.rdepth",
    "kls.lcurve", "kls.rcurve", "rate.scale", "ams", "vel", "level", "mode", "coarse", "fine", "detune")
  private val OP_MAX = intArrayOf(99, 99, 99, 99, 99, 99, 99, 99, 99, 99, 99, 3, 3, 7, 3, 7, 99, 1, 31, 99, 14)
  private val GLOBAL_FIELDS = listOf("fm.pitchenv.r1", "fm.pitchenv.r2", "fm.pitchenv.r3", "fm.pitchenv.r4",
    "fm.pitchenv.l1", "fm.pitchenv.l2", "fm.pitchenv.l3", "fm.pitchenv.l4", "fm.algorithm", "fm.feedback", "fm.oscsync",
    "fm.lfo.speed", "fm.lfo.delay", "fm.lfo.pmd", "fm.lfo.amd", "fm.lfo.sync", "fm.lfo.wave", "fm.lfo.pms", "fm.transpose")
  private val GLOBAL_MAX = intArrayOf(99, 99, 99, 99, 99, 99, 99, 99, 31, 7, 1, 99, 99, 99, 99, 1, 5, 7, 48)
  private fun globalOffset(g: Int) = when (g) { 8 -> -1; 18 -> 24; else -> 0 }
  private fun opOffset(k: Int) = if (k == 20) 7 else 0

  /** INIT VOICE, in VCED bytes; also the source of defaults for missing parameters. */
  private val INIT: IntArray = IntArray(155).also { p ->
    for (op in 0 until 6) {
      val o = op * 21
      for (i in 0..6) p[o + i] = 99
      p[o + 8] = 39; p[o + 16] = if (op == 5) 99 else 0; p[o + 18] = 1; p[o + 20] = 7
    }
    for (i in 126..129) p[i] = 99
    for (i in 130..133) p[i] = 50
    p[136] = 1; p[137] = 35; p[141] = 1; p[143] = 3; p[144] = 24
    "INIT VOICE".forEachIndexed { i, c -> p[145 + i] = c.code }
  }

  /** A bank or a single voice. [label] names the category ("DX7 <label>"). Throws [PresetError]. */
  fun readAny(bytes: ByteArray, label: String): Read = when (bytes.size) {
    4104 -> readBank(bytes, label)
    163 -> readVoice(bytes, label)
    else -> throw PresetError("Não é um arquivo do DX7")
  }

  fun readBank(b: ByteArray, label: String): Read {
    val u = IntArray(b.size) { b[it].toInt() and 0xFF }
    if (u.size != 4104 || u[0] != 0xF0 || u[1] != 0x43 || (u[2] and 0xF0) != 0 || u[3] != 0x09 || u[4] != 0x20 ||
      u[5] != 0x00 || u[4103] != 0xF7) throw PresetError("Não é um banco de 32 vozes do DX7")
    val presets = (0 until 32).map { i -> toPreset(unpackVmem(u, 6 + i * 128), label) }
    return Read(presets, checksum(u, 6, 4096) == (u[4102] and 0x7F))
  }

  private fun readVoice(b: ByteArray, label: String): Read {
    val u = IntArray(b.size) { b[it].toInt() and 0xFF }
    if (u[0] != 0xF0 || u[1] != 0x43 || (u[2] and 0xF0) != 0 || u[3] != 0 || u[4] != 1 || u[5] != 0x1B || u[162] != 0xF7)
      throw PresetError("Não é uma voz do DX7")
    val v = IntArray(155) { u[6 + it] }.also { clamp(it) }
    return Read(listOf(toPreset(v, label)), checksum(u, 6, 155) == (u[161] and 0x7F))
  }

  fun writeBank(presets: List<PresetFile>): ByteArray {
    val out = IntArray(4104)
    intArrayOf(0xF0, 0x43, 0x00, 0x09, 0x20, 0x00).copyInto(out)
    for (i in 0 until 32) packVmem(presets.getOrNull(i)?.let(::toVced) ?: INIT.copyOf(), out, 6 + i * 128)
    out[4102] = checksum(out, 6, 4096)
    out[4103] = 0xF7
    return ByteArray(out.size) { out[it].toByte() }
  }

  fun writeVoice(p: PresetFile): ByteArray {
    val v = toVced(p)
    val out = IntArray(163)
    intArrayOf(0xF0, 0x43, 0x00, 0x00, 0x01, 0x1B).copyInto(out)
    v.copyInto(out, 6)
    out[161] = checksum(out, 6, 155)
    out[162] = 0xF7
    return ByteArray(out.size) { out[it].toByte() }
  }

  /** VCED -> preset (fm.* parameters and engine.type only). */
  private fun toPreset(v: IntArray, label: String): PresetFile {
    val params = LinkedHashMap<String, Float>()
    params["engine.type"] = 1f
    for (n in 1..6) {
      val off = (6 - n) * 21
      OP_FIELDS.forEachIndexed { k, f -> params["fm.op$n.$f"] = (v[off + k] - opOffset(k)).toFloat() }
    }
    GLOBAL_FIELDS.forEachIndexed { g, f -> params[f] = (v[126 + g] - globalOffset(g)).toFloat() }
    val name = String(CharArray(10) { v[145 + it].toChar() }).trimEnd().ifBlank { "Sem nome" }
    return PresetFile(name = name, category = "DX7 $label", params = params)
  }

  /** Preset -> VCED. Missing fm.* parameters take the INIT VOICE value. */
  private fun toVced(p: PresetFile): IntArray {
    val v = INIT.copyOf()
    for (n in 1..6) {
      val off = (6 - n) * 21
      OP_FIELDS.forEachIndexed { k, f -> p.params["fm.op$n.$f"]?.let { v[off + k] = Math.round(it) + opOffset(k) } }
    }
    GLOBAL_FIELDS.forEachIndexed { g, f -> p.params[f]?.let { v[126 + g] = Math.round(it) + globalOffset(g) } }
    for (i in 0 until 10) {
      val c = p.name.getOrNull(i) ?: ' '
      v[145 + i] = if (c.code in 32..126) c.code else '?'.code
    }
    clamp(v)
    return v
  }

  private fun unpackVmem(m: IntArray, at: Int): IntArray {
    val v = IntArray(155)
    for (op in 0 until 6) {
      val s = at + op * 17
      val d = op * 21
      for (k in 0..10) v[d + k] = m[s + k] and 0x7F
      v[d + 11] = m[s + 11] and 3
      v[d + 12] = (m[s + 11] shr 2) and 3
      v[d + 13] = m[s + 12] and 7
      v[d + 20] = (m[s + 12] shr 3) and 0x0F
      v[d + 14] = m[s + 13] and 3
      v[d + 15] = (m[s + 13] shr 2) and 7
      v[d + 16] = m[s + 14] and 0x7F
      v[d + 17] = m[s + 15] and 1
      v[d + 18] = (m[s + 15] shr 1) and 0x1F
      v[d + 19] = m[s + 16] and 0x7F
    }
    for (i in 0 until 8) v[126 + i] = m[at + 102 + i] and 0x7F
    v[134] = m[at + 110] and 0x1F
    v[135] = m[at + 111] and 7
    v[136] = (m[at + 111] shr 3) and 1
    for (i in 0 until 4) v[137 + i] = m[at + 112 + i] and 0x7F
    v[141] = m[at + 116] and 1
    v[142] = (m[at + 116] shr 1) and 7
    v[143] = (m[at + 116] shr 4) and 7
    v[144] = m[at + 117] and 0x7F
    for (i in 0 until 10) v[145 + i] = m[at + 118 + i]
    clamp(v)
    return v
  }

  private fun packVmem(v: IntArray, out: IntArray, at: Int) {
    for (op in 0 until 6) {
      val s = op * 21
      val d = at + op * 17
      for (k in 0..10) out[d + k] = v[s + k]
      out[d + 11] = (v[s + 12] shl 2) or v[s + 11]
      out[d + 12] = (v[s + 20] shl 3) or v[s + 13]
      out[d + 13] = (v[s + 15] shl 2) or v[s + 14]
      out[d + 14] = v[s + 16]
      out[d + 15] = (v[s + 18] shl 1) or v[s + 17]
      out[d + 16] = v[s + 19]
    }
    for (i in 0 until 8) out[at + 102 + i] = v[126 + i]
    out[at + 110] = v[134]
    out[at + 111] = (v[136] shl 3) or v[135]
    for (i in 0 until 4) out[at + 112 + i] = v[137 + i]
    out[at + 116] = (v[143] shl 4) or (v[142] shl 1) or v[141]
    out[at + 117] = v[144]
    for (i in 0 until 10) out[at + 118 + i] = v[145 + i]
  }

  private fun clamp(v: IntArray) {
    for (op in 0 until 6) for (k in 0 until 21) v[op * 21 + k] = (v[op * 21 + k] and 0x7F).coerceIn(0, OP_MAX[k])
    for (g in 0 until 19) v[126 + g] = (v[126 + g] and 0x7F).coerceIn(0, GLOBAL_MAX[g])
    for (i in 145 until 155) v[i] = (v[i] and 0x7F).let { if (it < 32) ' '.code else it }
  }

  private fun checksum(u: IntArray, from: Int, n: Int): Int {
    var sum = 0
    for (i in from until from + n) sum += u[i]
    return (-sum) and 0x7F
  }
}
```

### Task 12: The algorithm drawing

**Files:**

**Where the topology comes from.** We do not keep a second hand-written copy of the 32 algorithms. msfa's table holds one flag byte per operator. It is exported once at start-up through JNI and decoded in Kotlin.

The table is `protected`, so `jni.cpp` uses a subclass:

```cpp
#include "fm_core.h"
struct AlgoPeek : FmCore {
  void render(int32_t*, FmOpParams*, int32_t, int32_t*, int32_t) override {}
  static int32_t flags(int alg, int op) { return algorithms[alg].ops[op]; }
};
JNI(jintArray, fmAlgorithms)(JNIEnv* env, jobject) {
  jint buf[32 * 6];
  for (int a = 0; a < 32; ++a) for (int o = 0; o < 6; ++o) buf[a * 6 + o] = AlgoPeek::flags(a, o);
  jintArray out = env->NewIntArray(32 * 6);
  env->SetIntArrayRegion(out, 0, 32 * 6, buf);
  return out;
}
```

`jni.cpp` is compiled with `volt_engine`'s public include path, which carries `MSFA_DIR` (Task 1). If the `render` signature differs in the Synth_Dexed version you vendored, copy it from `fm_core.h`.

**Decoding**, in msfa order (index 0 = OP6, processed first). For each operator, the flags are:
- `outBus = flags & 3`: 0 = the main output, 1 = bus 1, 2 = bus 2;
- `add = flags & 4`: add to what is already on that bus (on the main output, add is always set);
- `inBus = (flags >> 4) & 3`: 0 = no modulation input;
- `fbIn = flags & 0x40`, `fbOut = flags & 0x80`: the operator with both bits is fed back by itself (on every DX7 algorithm, feedback is a self-loop on a single operator, or a loop through the operators that carry the bits; draw an arrow from the `fbOut` operator to the `fbIn` operator).

Keep the set of operators currently on each bus. Process the operators in order:
1. If `inBus != 0`, the operator's modulators are the current set on `inBus`.
2. Then write: if `outBus == 0`, the operator is a carrier. Otherwise, if `add` is set, add the operator to the set on `outBus`; if not, replace that set with `{operator}`.
